SERVICES & ACCOUNTS - Cooper Fitness (cooper.fitness)
=====================================================

1. DOMAIN: cooper.fitness
   Provider:   (check your domain registrar, e.g. Namecheap, GoDaddy, Google Domains)
   Purpose:    Primary domain for the marketing site
   DNS:        Points to Vercel for hosting
   Email:      evan@cooper.fitness (inquiry recipient)

2. VERCEL - Hosting & Deployment
   Dashboard:  https://vercel.com/dashboard
   Purpose:    Hosts the Next.js site and serverless API routes
   Domain:     cooper.fitness configured as custom domain
   Env vars required:
     NEXT_PUBLIC_SITE_URL          = https://cooper.fitness
     NEXT_PUBLIC_RECAPTCHA_SITE_KEY
     RECAPTCHA_SECRET_KEY
     EMAILJS_SERVICE_ID
     EMAILJS_TEMPLATE_ID
     EMAILJS_PUBLIC_KEY
     EMAILJS_PRIVATE_KEY
     NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
     STRIPE_SECRET_KEY
     STRIPE_WEBHOOK_SECRET
     CRM_WEBHOOK_URL               (optional - lead forwarding)
     CRM_WEBHOOK_SECRET            (optional - lead forwarding auth)

3. EMAILJS - Inquiry and Purchase Email Delivery
   Dashboard:  https://dashboard.emailjs.com
   Purpose:    Sends inquiry and purchase notifications to evan@cooper.fitness
   NOTE:       "Allow API access from non-browser environments" must be ON
               (Settings: https://dashboard.emailjs.com/admin/account/security)
   Keys used:  Service ID, Template ID, Public Key, Private Key
   Template variables:  to_email, from_name, from_email, message

4. GOOGLE reCAPTCHA v2 - Bot / Spam Protection
   Dashboard:  https://www.google.com/recaptcha/admin
   Purpose:    Protects inquiry forms (modal + footer) from spam bots
   Type:       reCAPTCHA v2 "I'm not a robot" checkbox
   Domains allowed:  cooper.fitness, localhost

5. STRIPE - Payments
   Dashboard:  https://dashboard.stripe.com
   Purpose:    Processes coaching plan payments with the Payment Element
   Webhook:    /api/stripe-webhook
   Event:      payment_intent.succeeded
   Key note:   Prefer a restricted live API key (rk_live_...) for the server key.

6. SOCIAL MEDIA ACCOUNTS
   Instagram:  https://instagram.com/_cooperfitness
   YouTube:    https://youtube.com/@cooperfitness
   Twitter/X:  https://twitter.com/cooperfitnessx

7. IMAGE ASSETS
   Purpose:    Local brand imagery served from the public directory
   Files:      public/evanactionweb.png, public/evanselfiegym.jpeg

8. CRM WEBHOOK (Optional)
   Purpose:    Forward inquiry leads and paid clients to an external CRM
   Endpoint:   ${CRM_WEBHOOK_URL}/api/webhooks/new-lead
   Controlled by the CRM_WEBHOOK_URL and CRM_WEBHOOK_SECRET env vars
